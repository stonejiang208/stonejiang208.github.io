<h3>使用提示</h3>
<ul>
  <li><strong>转义下划线</strong>：在 LaTeX 公式中，下划线必须转义为 <code>\_</code></li>
  <li><strong>行内公式</strong>：使用 <code>$...$</code> 包裹公式</li>
  <li><strong>显示公式</strong>：使用 <code>$$...$$</code> 包裹公式（单独一行）</li>
  <li><strong>大括号</strong>：使用 <code>\{</code> 和 <code>\}</code> 表示大括号</li>
  <li><strong>反斜杠</strong>：所有 LaTeX 命令都以反斜杠开头</li>
</ul>

工具功能说明

1. 实时预览

  • 输入 LaTeX 代码，立即查看渲染结果
  • 支持行内公式 ($...$) 和显示公式 ($$...$$)
  • 显示原始代码和 MathJax 渲染结果

2. 常用示例

  • 提供 8 个常用公式示例
  • 点击示例卡片自动加载
  • 覆盖常见数学表达式类型

3. 使用提示

  • LaTeX 语法注意事项
  • 常见错误避免方法
  • 最佳实践建议

4. 响应式设计

  • 适配桌面和移动设备
  • 清晰的界面布局
  • 友好的用户体验

使用方法

  1. 在左侧文本框中输入 LaTeX 公式
  2. 点击”渲染公式”按钮查看结果
  3. 使用示例快速测试常见公式
  4. 参考使用提示避免常见错误

技术实现

这个工具使用与博客相同的 MathJax 配置，确保预览结果与实际发布效果一致。所有公式都通过服务器端 MathJax 渲染，避免了前端脚本冲突。

注意：为了确保公式在 GitHub Pages 上正确显示，请记住： - 所有下划线必须转义为 \_ - 使用正确的数学环境分隔符 - 避免在公式中使用 Markdown 语法

这个工具会定期更新，添加更多功能和示例。如果你有建议或发现问题，请在 GitHub 仓库中提交 Issue。
