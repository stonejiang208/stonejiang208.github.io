📚 最佳实践

写作规范

  1. 一致性：保持公式风格一致
  2. 可读性：适当添加空格和换行
  3. 注释：复杂公式添加注释
  4. 测试：发布前测试公式显示

性能优化

  1. 公式数量：每页不超过 20 个复杂公式
  2. CDN 使用：启用 MathJax CDN
  3. 懒加载：考虑实现公式懒加载
  4. 缓存：利用浏览器缓存

移动端优化

  1. 响应式设计：使用媒体查询
  2. 字体大小：适当调整公式大小
  3. 水平滚动：允许复杂公式水平滚动
  4. 触摸优化：确保公式可点击区域足够大

可访问性

  1. Alt 文本：为重要公式添加描述
  2. 键盘导航：确保公式可键盘访问
  3. 屏幕阅读器：测试屏幕阅读器兼容性
  4. 颜色对比：确保公式颜色对比度足够

🔍 故障排除

诊断步骤

  1. 检查控制台：打开浏览器开发者工具，查看控制台错误
  2. 验证语法：使用预览工具检查语法
  3. 测试环境：在不同浏览器和设备上测试
  4. 查看日志：检查 Hexo 生成日志

常见错误消息

调试工具

  1. MathJax 调试：在控制台输入 MathJax.config 查看配置
  2. 网络分析：检查 MathJax 脚本加载情况
  3. 性能分析：使用浏览器性能工具分析渲染时间
  4. 内存分析：检查内存使用情况
