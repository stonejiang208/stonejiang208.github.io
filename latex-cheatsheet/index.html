<h3>使用提示</h3>
<ul>
  <li><strong>行内公式</strong>: 使用 <code>$...$</code> 包裹公式，例如 <code>$E = mc^2$</code></li>
  <li><strong>显示公式</strong>: 使用 <code>$$...$$</code> 包裹公式，公式会单独成行显示</li>
  <li><strong>转义下划线</strong>: 在 LaTeX 公式中，下划线 <code>_</code> 必须转义为 <code>\_</code></li>
  <li><strong>复制使用</strong>: 点击"复制"按钮获取 LaTeX 代码，粘贴到你的文章中</li>
  <li><strong>搜索功能</strong>: 使用搜索框快速找到需要的符号</li>
</ul>
