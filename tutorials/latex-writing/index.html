🐛 常见错误与调试

错误1：未定义的控制序列

解决：检查命令拼写，或添加必要的包。

错误2：缺少 $

解决：确保数学环境用 $$...$$ 包裹。

错误3：数学模式错误

解决：检查括号匹配，确保所有 { 都有对应的 }。

调试技巧

  1. 逐段测试：将复杂公式分解测试

  4. 简化公式：先写简单版本，逐步复杂化

🎓 结业项目

项目要求

创建一个包含以下内容的数学文章： 1. 至少 5 种不同类型的公式 2. 使用自定义命令 3. 包含定理和证明 4. 优化移动端显示 5. 通过所有语法检查

评估标准

  1. 正确性：公式语法正确，渲染正常
  2. 美观性：排版整洁，间距合理
  3. 性能：加载快速，内存使用合理
  4. 可读性：结构清晰，注释恰当

提交方式

  1. 在 GitHub Issues 提交文章
  2. 使用标签 [教程作业]
  3. 包含公式截图和性能数据
