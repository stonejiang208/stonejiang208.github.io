常见问题与解决方案

问题1：矩阵显示为行向量

症状：矩阵或行列式显示为一行，而不是列向量格式。

原因：下划线被 Markdown 解析为斜体标记。

解决方案：转义所有下划线。

问题2：本地和 GitHub Pages 显示不一致

症状：本地预览正常，但 GitHub Pages 上公式显示异常。

原因：Markdown 渲染器配置不同。

解决方案：

  1. 使用 hexo-renderer-marked 而不是 hexo-renderer-markdown-it
  2. 使用服务器端 MathJax 渲染
  3. 禁用主题的前端数学渲染

问题3：公式渲染缓慢

症状：页面加载时公式显示延迟。

解决方案：

  1. 使用服务器端 MathJax 渲染（已配置）
  2. 考虑使用 CDN 加速 MathJax 加载
  3. 避免在单篇文章中使用过多复杂公式

最佳实践总结

  1. 始终转义下划线：_ → \_
  2. 使用正确的渲染器：hexo-renderer-marked
  3. 启用服务器端渲染：hexo-filter-mathjax
  4. 禁用前端渲染：在主题配置中禁用 MathJax 和 KaTeX
  5. 文章头部配置：添加 mathjax: true
  6. 验证流程：本地生成 → 检查 HTML → 部署验证
  7. 定期检查：新文章发布前检查 LaTeX 语法
