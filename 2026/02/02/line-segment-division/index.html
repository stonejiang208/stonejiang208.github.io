线段划分完整教程：缠论核心技能系统解析

线段是缠论技术分析的”原子”，是构建中枢、走势类型的基石。本教程基于第67、71、78课内容，系统讲解线段划分的完整方法论。

一、为什么线段如此重要

1.1 线段的地位

缠师的定位：

“有了这两个基础（笔和线段的划分），那么整个中枢与走势类型的递归体系就可以建立起来。这是基础的基础，请务必搞清楚，否则肯定学不好。”

1.2 线段的核心价值

价值 说明
唯一性 同一级别图上的走势可以唯一地划分为线段的连接
稳定性 线段比笔更稳定，不会因为一两笔的波动而改变
可操作性 线段是构建中枢的原材料，是走势分析的基石
破坏性 线段破坏是走势转折的标志，是操作的关键信号

二、线段的基本概念

2.1 线段的定义

线段是至少被另一线段破坏的走势段。

关键性质： - 线段有方向性 - 线段由笔构成 - 线段至少由三笔构成 - 线段必须被后续线段破坏才能确认结束

2.2 线段的方向

基本规则：

“由于向上的笔的开始分型是底，而向下笔的结束分型也是底，换言之，一个线段，不可能是从底到底或从顶到顶”

2.3 线段与笔的关系

特征序列：

“序列X1X2…Xn成为以向上笔开始线段的特征序列；序列S1S2…Sn成为以向下笔开始线段的特征序列。”

三、特征序列详解

3.1 特征序列的定义

为什么要引入特征序列？

因为线段的方向与笔的方向是相反的，所以我们需要一个”反向的序列”来描述线段的特征，这就是特征序列。

3.2 特征序列的图解

关键性质：

“容易证明，任何Si与Si+1之间，一定有重合区间。而考察序列X1X2…Xn，该序列中，Xi与Xi+1之间并不一定有重合区间”

3.3 缺口的概念

定义：特征序列两相邻元素间没有重合区间，称为该序列的一个缺口

四、特征序列的包含关系处理

4.1 为什么需要包含处理

就像K线图中的分型需要处理包含关系一样，特征序列也需要处理包含关系，这样才能准确找到分型点。

4.2 包含处理的原则

规则1：只有同一特征序列内的元素才能讨论包含关系

“特征序列的元素包含关系，首先的前提是这元素都在一特征序列里，如果两个不同的特征序列之间的元素，讨论包含关系是没意义的”

规则2：特征序列元素的方向相反，不可能包含

“特征序列的元素的方向，和其对应的段的方向是刚好相反的，例如，一个向上段后接着一个向下段，前者的特征序列元素是向下的，后者是向上的，因此，根本也不可能存在包含的可能”

规则3：假设转折点前后的两个元素不存在包含关系

“假设的转折点前后那两元素，是不存在包含关系的，因为，这两者已经被假设不是同一性质的东西”

4.3 包含处理的方法

标准特征序列：经过非包含处理的特征序列

处理方向： - 向上笔开始的线段 → 向下处理（取低点更低的） - 向下笔开始的线段 → 向上处理（取高点更高的）

五、线段划分的两种情况

5.1 情况一：无缺口的情况

特征：特征序列的分型中，第一和第二元素间不存在特征序列的缺口

判断方法： 1. 取特征序列的前三个元素 2. 看第一和第二元素之间是否有缺口 3. 如果没有缺口 → 情况一

线段结束位置：

线段类型 结束位置
向上笔开始的线段 顶分型的高点处
向下笔开始的线段 底分型的低点处

5.2 情况二：有缺口的情况

特征：特征序列的分型中，第一和第二元素间存在特征序列的缺口

判断方法： 1. 取特征序列的前三个元素 2. 看第一和第二元素之间是否有缺口 3. 如果有缺口 → 情况二

线段结束位置：

线段类型 结束位置
向上笔开始的线段 从该分型最高点开始的向下一笔开始的序列出现底分型 → 该顶分型的高点
向下笔开始的线段 从该分型最低点开始的向上一笔开始的序列出现顶分型 → 该底分型的低点

七、笔破坏与线段破坏

7.1 笔破坏的定义

笔破坏是指：一笔破坏了前一线段的特征序列。

条件： - 有一笔向上突破了前一线段的最高点 - 或有一笔向下突破了前一线段的最低点

7.2 线段破坏的充要条件

“线段破坏的充要条件就是被另一个线段破坏”

精确表达： - 必须出现笔破坏 - 笔破坏后，特征序列必须出现分型 - 特征序列的分型必须满足两种情况之一

7.3 笔破坏与线段破坏的关系

关系： - 线段破坏必须先有笔破坏 - 但笔破坏不一定导致线段破坏 - 只有笔破坏最终发展成线段破坏，线段才确认结束

八、古怪线段的成因

8.1 什么古怪线段

“所谓的古怪，是一点都不古怪，只是一般人心里有一个印象，觉得线段都是一波比一波高或低，很简单那种，其实，线段完全不必要这样”

常见古怪情况： - 特征序列出现包含关系 - 笔破坏后没有形成线段破坏 - 高低点不是线段的端点

8.2 古怪线段的唯一原因

“所有古怪的线段，都是因为线段出现第一种情况的笔破坏后最终没有在该方向由该笔发展形成线段破坏所造成的”

过程： 1. 线段出现第一种情况的笔破坏（有缺口） 2. 但没有形成特征序列的分型 3. 最终没有在该方向形成线段破坏 4. 导致线段结构看起来”古怪”

8.3 处理方法

关键认知：

“线段出现第一种情况的笔破坏后最终没有在该方向由该笔发展形成线段破坏时，在上面例子中的向上破坏笔完成后，接下来肯定是向下的笔，这笔肯定会形成一个向下的线段”

处理原则： 1. 如果向下的笔破了向上破坏笔的底 → 原线段继续延续 2. 如果向下的笔没有破向上破坏笔的底 → 可以确认线段被破坏

九、线段的标准处理

9.1 标准化处理

“如果线段中，最高或最低点不是线段的端点，那么，在任何以线段为基础的分析中，例如把线段为基础构成最小级别的中枢等，都可以把该线段标准化为最高低点都在端点”

标准化方法：

目的： - 把线段当成没有内部结构的基本部件 - 只关心线段的实际区间（高低点） - 方便后续中枢和走势类型的分析

9.2 标准化后的性质

意义：

“这样，所以线段的连接，就形成一条延续不断、首尾相连的折线，这样，复杂的图形，就会十分地标准化，也为后面的中枢、走势类型等分析提供了最标准且基础的部件”

10.1 问题1：如何判断特征序列的缺口

问：特征序列的元素之间怎么判断是否有缺口？

答：看两个元素是否有重叠

10.2 问题2：转折点的确定

问：如何确定一个转折点是两线段的分界点？

答：按照以下流程

10.3 问题3：线段划分的唯一性

问：同一个图形，不同人划分结果不同怎么办？

答：

“线段的划分，都是可以当下完成的，无非是如下的程序：假设某转折点是两线段的分界点，然后对此用线段划分的两种情况去考察是否满足”

原则： - 严格按照定义划分 - 同一级别图上的走势可以唯一划分 - 如果划分不唯一，一定是基本概念没搞清楚

10.4 问题4：包含关系的处理

问：特征序列的包含关系怎么处理？

答：分三种情况

包含处理方向： - 向上处理：取高点更高的（适用于向下笔开始的线段） - 向下处理：取低点更低的（适用于向上笔开始的线段）

十二、总结：线段划分的核心要点

12.1 核心定义

概念 定义
线段 至少被另一线段破坏的走势段
特征序列 与线段方向相反的笔序列
缺口 特征序列相邻元素无重叠
标准特征序列 经过包含处理的特征序列

12.2 两种划分情况

情况 条件 结束判断
情况一 特征序列第一、二元素间无缺口 直接确认分型处结束
情况二 特征序列第一、二元素间有缺口 需要后续分型确认

12.3 关键规则

  1. 方向规则：向上线段从底到顶，向下线段从顶到底
  2. 破坏规则：线段破坏必须被另一线段破坏
  3. 唯一性规则：同一级别图可唯一划分线段
  4. 标准化规则：线段可标准化为高低点都在端点

  1. 深刻理解定义：特征序列、缺口、包含关系的本质
