缠论背驰识别方法完整体系

引言

背驰是缠论技术分析中最核心的概念之一，它是判断走势转折的关键工具。缠师曾说过：“背驰是制造买卖点的”，准确识别背驰是实战操作的基础。本文将根据缠论原文，系统梳理背驰的识别方法，帮助读者建立完整的背驰判断体系。

一、背驰的基本概念与前提

1.1 最基本前提：没有趋势，没有背驰

这是缠论背驰理论的核心前提。缠师在第15课中明确指出：

“转折，一般只有两种：一、’湿吻’后继续原趋势形成陷阱后回头制造出转折；二、出现盘整，以时间换空间地形成转折。必须注意：没有趋势，没有背驰。在盘整中是无所谓’背驰’的，这点是必须特别明确的。”

这意味着： - 背驰只能发生在趋势走势中 - 盘整走势中的类似背驰现象称为”盘整背驰” - 趋势的定义是必须有两个同级别的中枢

1.2 趋势的定义与结构

趋势分为上涨趋势和下跌趋势两种：

上涨趋势： - 由两个同级别中枢组成 - 中枢不断创新高 - 结构：a + A + b + B + c

下跌趋势： - 由两个同级别中枢组成 - 中枢不断创新低 - 结构类似，方向相反

结构说明： - A、B是两个同级别中枢 - a是连接段（进入段） - b是连接段（中枢间连接） - c是背驰段（离开段）

1.3 背驰与盘整背驰的区别

特征 趋势背驰 盘整背驰
中枢数量 2个同级别 1个
发生场景 趋势走势末尾 盘整走势中
转折力度 较强 相对较弱
是否创新高 必须创新高 不必创新高
回跌幅度 至少回到B中枢 视情况而定

二、背驰的数学定义

2.1 缠中说禅趋势力度

缠师在第15课中给出了背驰的数学定义——缠中说禅趋势力度：

“前一’吻’的结束与后一’吻’开始由短线均线与长期均线相交所形成的面积。在前后两个同向趋势中，当缠中说禅趋势力度比上一次缠中说禅趋势力度要弱，就形成’背驰’。”

计算步骤： 1. 选择两条均线（短线和长线） 2. 计算两均线相交所形成的面积 3. 比较相邻两段同向趋势的面积 4. 后一段面积 < 前一段面积 → 背驰

2.2 两种判断方法

方法一：事后确认法

这是最稳妥的方法，但有一个缺点——必须等再次接吻后才能判断，这时候走势离真正的转折点会已经有一点距离。

缠师提供的解决方法是： > “看低一级别的图，从中按该种办法找出相应的转折点。这样和真正的低点基本没有太大的距离。”

方法二：趋势平均力度法

这是一种技巧比较高的方法：

定义：当下与前一”吻”的结束时短线均线与长期均线形成的面积除以时间。

判断步骤： 1. 计算当下的趋势平均力度 2. 与前一次趋势平均力度对比 3. 这次比上次弱 → 判断”背驰”即将形成 4. 然后根据短线均线与长期均线的距离，一旦延伸长度缩短，就意味着真正的底部马上形成

缠师指出这种方法： > “优点：真正的转折点基本可以完全同时地抓住。缺点：风险稍微大点，且需要的技巧要高点，对市场的感觉要好点。”

三、MACD辅助判断方法

3.1 MACD指标基础

MACD辅助判断是缠师在第24课中详细讲解的方法，这种方法对大多数人来说更容易理解和把握。

MACD指标构成： - 黄白线：DIFF和DEA - 红绿柱子：MACD柱 - 0轴：红绿柱子交界的直线

3.2 MACD判断背驰的前提

使用MACD判断背驰，必须满足以下结构：

“用MACD判断背驰，首先要有两段同向的趋势。同向趋势之间一定有一个盘整或反向趋势连接，把这三段分别称为A、B、C段。显然，B的中枢级别比A、C里的中枢级别都要大，否则A、B、C就连成一个大的趋势或大的中枢了。A段之前，一定是和B同级别或更大级别的一个中枢，而且不可能是一个和A逆向的趋势，否则这三段就会在一个大的中枢里了。”

归纳总结：

3.3 背驰的判断标准

当C段走势类型完成时： - 对应的MACD柱子面积比A段小 - 向上趋势：看红柱子面积 - 向下趋势：看绿柱子面积

这时候就构成标准的背驰。

3.4 面积计算的实用技巧

缠师提供了一个非常实用的技巧：

“不需要等柱子全出来，一般柱子伸长的力度变慢时，把已经出现的面积乘2，就可以当成是该段的面积。所以，实际操作中根本不用回跌后才发现背驰，在上涨或下跌的最后阶段，判断就出来了，一般都可以抛到最高价位和买在最低价位附近。”

这个技巧的意义在于： - 不用等待走势完全走完 - 在走势进行中就能预判 - 大大提高操作的时效性

四、趋势背驰的严格条件

4.1 第37课的深化

在第37课”背驰的再分辨”中，缠师对趋势背驰的判断条件进行了严格的澄清和规范，这是对之前内容的深化和完善。

4.2 条件一：A、B必须同级别

“一个趋势，就意味着A、B是同级别的中枢，否则，就只能看成是其中较大中枢的一个震荡。”

如果A的级别比B大：

这种情况下： - a与(b+B+c)就是围绕中枢A的小级别波动 - 不存在趋势背驰 - 最多只有盘整背驰

4.3 条件二：c必须是次级别

“c至少包含对B的一个第三类买卖点，否则，就可以看成是B中枢的小级别波动，完全可以用盘整背驰来处理。”

关键点： - c段必须确认离开中枢B的有效性 - 这是趋势背驰的必要条件

4.4 条件三：b的级别不能大于c

“b是有可能小于次级别的，力度最大的就是连续的缺口，也就是说，b在级别上是不能大于c的。”

重要说明： - 如果b是次级别，而c出现连续缺口 - 即使c没完成，最终也延续成次级别 - c是背驰的可能性就很小了 - 即使背驰，也要特别留意出现最弱走势的可能性

4.5 条件四：c必须创新高/新低

“如果a+A+b+B+c是上涨，c一定要创出新高；如果a+A+b+B+c是下跌，c一定要创出新低。否则，就算c包含B的第三类买卖点，也可以对围绕B的次级别震荡用盘整背驰的方式进行判断。”

补充说明： > “连新高都创不出，力度就最弱，当然更不行。这时候，连MACD辅助都没必要。MACD只要是辅助创新高的情况。”

4.6 条件五：c的内部结构

“对c的内部进行分析，由于c包含B的第三类买卖点，则c至少包含两个次级别中枢，否则满足不了次级别离开后次级别回拉不重回中枢的条件。这两个中枢构成次级别趋势的关系，是最标准最常见的情况。”

区间套分析方法： 可以继续套用a+A+b+B+c的形式进行次级别分析，形成类似区间套的状态，对背驰进行更精确的定位。

五、盘整背驰的判断方法

5.1 盘整背驰的定义

缠师在第24课中说明：

“为明确起见，一般不特别声明的，背驰都指最标准的趋势中形成的背驰。而盘整用，利用类似背驰的判断方法，也可以有很好的效果。这种盘整中的类似背驰方法的应用，称为盘整背驰判断。”

5.2 盘整背驰的两种情况

情况一：C段不破中枢

“如果C段不破中枢，一旦出现MACD柱子的C段面积小于A段面积，其后必定有回跌。”

情况二：C段上破中枢

“如果C段上破中枢，但MACD柱子的面积小于A段的，这时候的原则是先出来，其后有两种情况：1. 如果回跌不重新跌回，就在次级别的第一类买点回补，刚好这反而构成该级别的第三类卖点；2. 如果回跌重新跌回，就继续该盘整。”

5.3 盘整背驰后的走势特点

“盘整背驰出来，并不一定都要大幅下跌，否则怎么会有第三类买点构成的情况。”

万科案例： 缠师举例说明万科的走势： - 12月15日10点45分构成一个盘整背驰 - 其后的次级别回跌并不重新回到前面的中枢里 - 18日9点45分构成了标准的第三类买点 - 这时候就该重新回补了

六、小级别背驰引发大级别转折

6.1 必要条件

缠师在第44课中给出了缠中说禅小背驰-大转折定理：

“小级别顶背驰引发大级别向下的必要条件是该级别走势的最后一个次级别中枢出现第三类卖点；小级别底背驰引发大级别向上的必要条件是该级别走势的最后一个次级别中枢出现第三类买点。”

重要提示： > “注意，关于这种情况，只有必要条件，而没有充分条件，也就是说不能有一个充分的判断使得一旦出现某种情况，就必然导致大级别的转折。”

6.2 操作策略

对于不同情况的应对策略：

情况一：背驰级别等于当下的走势级别 > “如果你刚好是该级别为操作级别的，只要在顶背驰时直接全部卖出就可以。”

情况二：背驰级别小于当下的走势级别 > “当见到1分钟的顶背驰时，也可以把部分筹码出掉，然后根据后面的回调走势情况决定回补还是继续出。这对一定量的资金是唯一可行的，因为这种资金，不可能在任何一定级别的卖点都全仓卖掉。”

七、背驰与级别的关系

7.1 级别决定转折幅度

缠师在第24课中详细说明了级别与背驰的关系：

“背驰的回跌力度，和级别很有关系。”

日线上涨的中段刚开始： - MACD刚创新高，红柱子伸长力度强劲 - 5分钟即使出现背驰，下跌力度有限 - 只能打点短差，甚至可以不管

日线走势的最后阶段（上涨延伸）： - 1分钟的背驰足以引发暴跌 - 必须多级别综合考察 - 绝对不能一看背驰就抛等跌50%

7.2 区间套方法

“进入背驰段，要找精确的卖点，就看1分钟以及以下的，这叫区间套方法。”

注意事项： - 对小级别的背驰，是否能引发大的调整，必须看大级别是否进入背驰段 - 例如5分钟的背驰，必须先看30分钟是否进入背驰段的可能 - 30分钟在主升段的，那5分钟的背驰往往就是一个盘中的小调整

八、缠中说禅MACD定律

在回复中，缠师给出了一个简洁的MACD定律：

“第一类买点都是在0轴之下背驰形成的，第二类买点都是第一次上0轴后回抽确认形成的。卖点的情况就反过来。”

这个定律为MACD辅助判断提供了简洁的操作指引。

九、完整判断流程

9.1 步骤一：确认走势类型

  1. 找到中枢数量
  2. 判断中枢级别
  3. 确认是趋势（2个中枢）还是盘整（1个中枢）

9.2 步骤二：趋势背驰检查

如果是趋势，需要检查以下条件：

  1. A、B是否同级别？
  2. c是否次级别？
  3. b的级别 ≤ c？
  4. c创新高/新低？
  5. c内部是否包含两个次级别中枢？
  6. MACD面积比较（C段 < A段）？

9.3 步骤三：盘整背驰检查

如果不符合趋势，检查：

  1. 是否中枢内背驰？→ MACD面积比较
  2. 是否中枢突破后背驰？→ MACD面积比较 + 是否重回中枢

9.4 步骤四：确定背驰类型

类型 后续走势预期
趋势背驰 至少回到B中枢
盘整背驰 观察是否形成第三类卖点

9.5 步骤五：制定操作策略

  • 趋势背驰：卖出，等待回到中枢
  • 盘整背驰：根据是否破中枢分情况处理

十、常见错误与纠正

错误一：所有a+A+b+B+c都是趋势背驰

纠正：必须首先确认A、B同级别。如果A的级别比B大，那就不是趋势，而是围绕中枢A的震荡，最多只有盘整背驰。

错误二：忽略b的级别限制

纠正：b可以小于次级别（连续的缺口），但b的级别不能大于c。

错误三：c不创新高也判断背驰

纠正：上涨趋势中，c必须创新高；下跌趋势中，c必须创新新低。

错误四：光看柱子就判断背驰

纠正：缠师强调： > “背驰需要多少个条件？光柱子缩短就背驰？背驰和柱子缩短不是一回事情，不能把问题简单化了。各位一定要把MACD判断背驰的几个条件综合起来，不能光看柱子就完事。”

错误五：混淆背驰与背驰段

纠正： > “能延续的只能是背驰段，背驰段的延续，最终有可能导致背驰段的失效。所谓的背驰，就是成功了的背驰段，既然成功了，就不存在延续的问题。”

十一、实战要点总结

11.1 判断步骤

  1. 确认走势结构：A、B、C三段
  2. 确认B段中枢把黄白线回拉到0轴
  3. 比较C段与A段的MACD柱子面积
  4. C段面积更小 → 背驰成立

11.2 操作策略

  • 趋势背驰：卖出后等待，至少回到B段中枢
  • 盘整背驰：根据是否破中枢分两种情况处理

11.3 级别考虑

  • 1分钟背驰 → 小幅度回调
  • 日线背驰 → 大幅度逆转
  • 背驰级别与逆转幅度正相关

十二、学习建议

12.1 学习路径

第一阶段：理解基本前提（第15课） - 趋势定义 - 背驰前提 - 基本概念

第二阶段：掌握辅助工具（第24、25课） - MACD辅助判断 - 趋势力度计算 - 面积比较方法

第三阶段：深化理论理解（第37课） - 严格条件 - 级别关系 - 内部结构

第四阶段：应对复杂情况（第44课） - 小级别转折 - 大级别影响 - 复杂操作策略

12.2 练习方法

  1. 复盘历史走势：用MACD找到可能的背驰点，用理论验证
  2. 模拟操作：发现背驰信号后制定操作计划，按计划执行
  3. 逐步深入：从大级别开始，逐步深入到小级别

12.3 核心原则

缠师强调： > “都是方法，关键要精通一种，不要贪多。实际操作时，一种方法精通就足够了，最怕就是什么都懂点，什么都不通。”
