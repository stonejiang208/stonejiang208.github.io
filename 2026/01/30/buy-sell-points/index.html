缠论买卖点体系详解：三类买卖点的定义、识别与实战应用

发表于 2026-01-30 更新于 2026-02-02 分类于 缠论学习
本文字数： 3.7k 阅读时长 ≈ 3 分钟

买卖点体系是缠论技术分析的核心，是连接理论与实战的桥梁。缠论将所有的买卖点归结为三类，这三类买卖点构成了完整的操作体系。本文将深入解析缠论三类买卖点的定义、识别方法、实战应用及相互关系。 ## 买卖点体系概述

1. 买卖点的哲学基础

缠论买卖点体系建立在以下哲学基础上： - 走势必完美：任何级别的任何走势类型最终都必然完成 - 级别理论：买卖点必须明确其所属级别 - 递归体系：从最小级别递归构建高级别买卖点

2. 三类买卖点的关系

三类买卖点不是孤立的，而是有机联系的： - 所有买卖点最终都可以归到某级别的第一类买卖点 - 第二类买卖点是第一类买卖点的补充和确认 - 第三类买卖点是中枢结束的标志

第一类买卖点：趋势背驰点

1. 定义与特征

第一类买卖点是由趋势背驰构成的买卖点，是趋势转折的标志。

数学定义： - 上涨趋势的第一类卖点：上涨趋势背驰点 - 下跌趋势的第一类买点：下跌趋势背驰点

核心特征： - 发生在趋势的末端 - 必须有明确的背驰信号 - 是趋势转折的精确位置

2. 识别方法

趋势背驰的判断标准

根据缠论原文《教你炒股票15：没有趋势，没有背驰》：

  1. 前提条件：必须有明确的趋势（上涨或下跌）
  2. 力度比较：前后两个同向趋势的力度比较
  3. MACD辅助：C段对应的MACD柱子面积小于A段

具体判断步骤： 1. 确认走势处于明确的趋势中 2. 找出趋势中的A、B、C三段 3. 比较C段与A段的力度（MACD柱子面积） 4. 确认背驰信号

趋势背驰的数学表达

设一个标准的趋势走势为：a+A+b+B+c 其中： - A、B为同级别中枢 - a、b、c为次级别走势类型 - c为背驰段

当c段力度小于b段时，构成趋势背驰，形成第一类买卖点。

3. 实战应用

买入操作（第一类买点）

  • 位置：下跌趋势的末端
  • 信号：下跌背驰确认
  • 操作：分批建仓，控制仓位
  • 止损：背驰点下方适当位置

卖出操作（第一类卖点）

  • 位置：上涨趋势的末端
  • 信号：上涨背驰确认
  • 操作：分批减仓，锁定利润
  • 止盈：背驰点上方适当位置

4. 注意事项

  1. 没有趋势，没有背驰：盘整中不存在真正的背驰
  2. 级别确认：必须在明确的趋势级别上判断
  3. 多重验证：结合多个技术指标验证背驰
  4. 风险控制：第一类买卖点不是100%准确，需要风险控制

第二类买卖点：回抽确认点

1. 定义与特征

第二类买卖点是第一类买卖点后的回抽确认点。

数学定义： - 第二类买点：第一类买点后次级别回抽不创新低 - 第二类卖点：第一类卖点后次级别回抽不创新高

核心特征： - 发生在第一类买卖点之后 - 是对第一类买卖点的确认 - 位置相对安全，风险较小

2. 识别方法

第二类买卖点的判断标准

根据缠论原文：

  1. 前提条件：必须有明确的第一类买卖点
  2. 回抽确认：次级别走势回抽不创新高/新低
  3. 位置关系：与第一类买卖点形成对应关系

具体判断步骤： 1. 确认第一类买卖点已经形成 2. 观察次级别走势的回抽 3. 确认回抽不创新高/新低 4. 形成第二类买卖点

第二类买卖点的数学表达

设第一类买点为P1，其后走势为： - 次级别向上走势：确认第一类买点 - 次级别向下回抽：不跌破P1，形成第二类买点P2

同理，对于卖点： - 次级别向下走势：确认第一类卖点 - 次级别向上回抽：不突破P1，形成第二类卖点P2

3. 实战应用

第二类买点的优势

  1. 安全性高：经过第一类买点确认
  2. 位置明确：回抽不创新低的位置
  3. 风险可控：止损位置清晰
  4. 成功率高：经过市场验证

第二类卖点的优势

  1. 利润锁定：避免过早卖出
  2. 确认充分：经过回抽确认
  3. 避免踏空：给趋势延续的机会
  4. 操作稳健：风险收益比合理

4. 与第一类买卖点的关系

根据缠论原文《教你炒股票53》： > “在有第一类买卖点的情况下，第一类买卖点是最佳的，第二类只是一个补充；但在小级别转大级别的情况下，第二类买卖点就是最佳的，因为在这种情况下，没有该级别的第一类买卖点。”

关键点： 1. 最佳选择：有第一类买卖点时，优先选择第一类 2. 补充作用：第二类买卖点是对第一类的补充 3. 特殊情况：小级别转大级别时，第二类买卖点最佳

第三类买卖点：中枢突破点

1. 定义与特征

第三类买卖点是中枢突破后的回抽确认点，标志着中枢的结束。

数学定义（根据《教你炒股票20》）： - 第三类买点：一个次级别走势类型向上离开缠中说禅走势中枢，然后以一个次级别走势类型回试，其低点不跌破ZG（中枢高点） - 第三类卖点：一个次级别走势类型向下离开缠中说禅走势中枢，然后以一个次级别走势类型回抽，其高点不升破ZD（中枢低点）

核心特征： - 发生在中枢被突破后 - 是对中枢突破的确认 - 标志着原中枢的结束

2. 识别方法

第三类买卖点的判断标准

根据缠论原文《教你炒股票20》的严格定义：

第三类买点的条件： 1. 一个次级别走势向上离开中枢 2. 一个次级别走势回试中枢 3. 回试低点不跌破中枢高点ZG 4. 必须是第一次回试

第三类卖点的条件： 1. 一个次级别走势向下离开中枢 2. 一个次级别走势回抽中枢 3. 回抽高点不升破中枢低点ZD 4. 必须是第一次回抽

级别关系

  • 中枢级别：例如日线中枢
  • 次级别走势：例如30分钟走势
  • 次级别完成：需要再次级别（例如5分钟）呈现3段走势类型

3. 实战应用

第三类买点的操作

  1. 确认突破：次级别向上离开中枢
  2. 等待回试：次级别向下回试
  3. 确认买点：回试不破ZG，形成第三类买点
  4. 买入操作：在确认点买入
  5. 止损设置：ZG下方适当位置

第三类卖点的操作

  1. 确认突破：次级别向下离开中枢
  2. 等待回抽：次级别向上回抽
  3. 确认卖点：回抽不破ZD，形成第三类卖点
  4. 卖出操作：在确认点卖出
  5. 风险控制：ZD上方适当位置

4. 注意事项

根据缠论原文提醒：

  1. 不是任何回调都是第三类买卖点：必须是第一次
  2. 第三类买卖点后不必然是趋势：可能进入更大级别盘整
  3. 必然赢利的原因：即使是盘整，也会有高点出现
  4. 操作策略：一旦不能出现趋势，一定要在盘整的高点出掉

三类买卖点的综合应用

1. 买卖点的级别关系

根据缠论原文《教你炒股票53》： > “至于第一、二、三买卖点，归根结底都可以归到第一类买卖点上，只是级别不同。”

级别对应关系： - 同一级别的三类买卖点构成完整的操作体系 - 不同级别的买卖点可以相互转化 - 操作时需要明确买卖点的级别

2. 买卖点的选择策略

根据操作风格选择

  1. 激进型：主要操作第一类买卖点
  2. 稳健型：主要操作第二类买卖点
  3. 确认型：主要操作第三类买卖点

根据市场环境选择

  1. 趋势明确：优先第一类买卖点
  2. 震荡市场：优先第二类买卖点
  3. 突破行情：优先第三类买卖点

3. 买卖点的风险控制

仓位管理

  1. 第一类买卖点：轻仓试探，确认后加仓
  2. 第二类买卖点：正常仓位，风险可控
  3. 第三类买卖点：重仓操作，趋势明确

止损设置

  1. 第一类买卖点：背驰点下方/上方
  2. 第二类买卖点：第一类买卖点位置
  3. 第三类买卖点：ZG/ZD位置

实战案例分析

案例1：工商银行第三类买点

根据《教你炒股票20》中的经典案例： - 时间：2006年12月14日 - 级别：日线级别第三类买点 - 特征：次级别（30分钟）向上离开中枢，回试不破ZG - 结果：后续出现大幅上涨

案例2：北辰实业第三类买点

  • 时间：2006年11月14日
  • 级别：日线级别第三类买点
  • 特征：标准的中枢突破回抽确认
  • 结果：成为当时的大牛股

  • 时间：2007年1月20日
  • 级别：日线级别第三类卖点
  • 特征：次级别向下离开中枢，回抽不破ZD
  • 结果：后续出现大幅下跌

常见问题与解答

Q1：三类买卖点哪个最重要？

A：三类买卖点都重要，不能偏废。站在同一级别上，三者都重要。但在不同情况下有不同选择： - 有第一类买卖点时，第一类最佳 - 小级别转大级别时，第二类最佳 - 中枢突破确认时，第三类最佳

Q2：第三类买卖点后一定会出现趋势吗？

A：不一定。第三类买卖点后，并不必然是趋势，也有进入更大级别盘整的可能。但这种买卖之所以必然赢利，就是因为即使是盘整，也会有高点出现。

Q3：如何避免买卖点的误判？

A：避免误判的关键： 1. 严格按定义判断 2. 明确买卖点的级别 3. 多重技术指标验证 4. 结合市场环境分析 5. 做好风险控制

Q4：买卖点操作的资金管理？

A：建议的资金管理策略： 1. 第一类买卖点：30%仓位 2. 第二类买卖点：50%仓位 3. 第三类买卖点：70%仓位 4. 永远不要满仓操作 5. 严格设置止损

总结与建议

1. 核心要点总结

  1. 三类买卖点构成完整体系：第一类（背驰）、第二类（回抽）、第三类（突破）
  2. 级别关系明确：买卖点必须明确其级别
  3. 操作策略灵活：根据不同情况选择不同买卖点
  4. 风险控制严格：买卖点操作必须配合严格的风险控制

2. 学习建议

  1. 从定义入手：深入理解三类买卖点的严格定义
  2. 多看图练习：通过大量看图练习提高识别能力
  3. 小资金实践：先用小资金实践，积累经验
  4. 持续学习：缠论体系深奥，需要持续学习

3. 实战建议

  1. 明确操作级别：选择适合自己的操作级别
  2. 耐心等待信号：不要急于操作，等待明确的买卖点
  3. 严格执行纪律：按买卖点操作，不随意改变计划
  4. 持续总结经验：每次操作后总结经验教训
