从仿射组合到凸组合

仿射组合是线性组合的特殊形式. 线性组合 c_1v_1 + c_2v_2 + ⋯ + c_nv_n = ∑_i = 1nc_iv_i

其中 ∑_i = 1nc_i = 1

如果有 c_i ≥ 0  (i = 1, ⋯n) 那种这种特殊的线性组合称为凸组合.

一个集合S中所有凸组合的集称为S的凸包，记为convS.
