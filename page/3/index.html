从仿射组合到凸组合

仿射组合是线性组合的特殊形式. 线性组合 \[ {c_1} \mathbf{v_1}+ c_2 \mathbf{v_2} + \cdots + c{_n}\mathbf{v{_n}} = \sum_{i=1}^{n}{c_i\mathbf{v_i}} \]

其中 \[ \sum_{i=1}^{n} {c_i} = 1 \]

如果有 \[ c_i \geq 0 \quad (i = 1, \cdots n) \] 那种这种特殊的线性组合称为凸组合.

一个集合\(S\)中所有凸组合的集称为\(S\)的凸包，记为\(conv{}S\).

仿射

仿射组合是线性组合的特殊形式. 线性组合 \[ {c_1} \mathbf{v_1}+ c_2 \mathbf{v_2} + \cdots + c{_n}\mathbf{v{_n}} = \sum_{i=1}^{n}{c_i\mathbf{v_i}} \]

如果 \[ \sum_{i=1}^{n} {c_i} = 1 \]

那么这个线性组合就称为仿射组合.

如果所有的系数\(\_i \geq 0 \quad (i = 1,\cdots n)\)，且和为1，则称为单位线性组合.通常表示加权平均. (凸组合)

读书笔记（《老人与海》和《活着》》

发表于 2024-02-06 更新于 2024-09-23 分类于 阅读 ， 文学
本文字数： 1.2k 阅读时长 ≈ 1 分钟

最近一口气读了两中短篇小说：《老人与海》 和 《活着》。下面是一点随笔：

故事概述

《老》讲述了一位古巴老渔夫与一条巨大的马林鱼搏斗的故事，体现了人与自然的较量以及对生命意义的探索。

《活》描述了中国20世纪上半叶至文化大革命期间的历史背景下，一位普通农民的生活经历，以及在种种苦难中对生命的坚守与尊严的追求。

两部作品都涉及到人在极端环境下的顽强生存与坚韧不拔的精神。在《老人与海》中， 老渔夫与海洋巨鱼的搏斗是一种象征，表现了人类与自然界的对抗， 同时也反映了对命运的挑战与对生命的尊严的追求。而《活着》则通过一个农民的个人命运， 揭示了中国社会历史变迁中人性的光辉与荒诞，以及对生命的珍视与尊严的追求。

读这两部书可以让人反思生命的意义，面对困境时的态度，以及人与自然、人与社会的关系。 在不同的文化背景下，作者们都以其独特的视角揭示了人类生存的精神力量与价值观念。
