常见问题解决

1. 公式不显示

检查点： 1. 确保使用 $$ 或 $ 包围公式 2. 检查下划线是否转义：\_ 而不是 _ 3. 确认页面启用了 mathjax: true

2. 公式显示异常

常见问题： - 花括号问题：使用 \{ 和 \} 而不是 { 和 } - 特殊字符：使用 \#, \$, \%, \&, \_, \{, \} - 环境问题：确保 \begin{} 和 \end{} 配对使用

3. 性能优化

建议： 1. 避免在单个页面中使用过多复杂公式 2. 使用 \displaystyle 谨慎，可能影响性能 3. 考虑使用KaTeX替代MathJax以获得更好性能
